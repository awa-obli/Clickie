# Clickie 连点器

一个简洁、小巧的鼠标连点器，使用 Python/Tkinter 开发。ヾ(≧▽≦*)o

## 界面预览

使用[Sun Valley ttk主题](https://github.com/rdbende/Sun-Valley-ttk-theme)，跟随系统深浅模式。

## 功能

- 自定义热键
- 自定义点击间隔
- 支持切换左键/右键、单击/双击
- 支持设置点击次数

## 安装与运行

### 环境要求
- Python 3.7+
- Windows

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行

```bash
python clickie.py
```
